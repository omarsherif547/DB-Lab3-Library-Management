Lab 3 – Problem 1 Answers

Q1.1 – Delete a referenced employee

SQL:
```sql
DELETE FROM EMPLOYEE
WHERE ssn = '100000001';
```

Expected result:
The DELETE statement fails because this employee is referenced by DEPARTMENT.mgr_ssn. MySQL prevents deleting a referenced row to preserve referential integrity. Expected error: Error 1451.

Q1.2 – Insert a project referencing a nonexistent department

SQL:
```sql
INSERT INTO PROJECT
(Pnumber, Pname, Plocation, Dno)
VALUES
(4, 'Test Project', 'Alexandria', 99);
```

Expected result:
The INSERT statement fails because department number 99 does not exist in DEPARTMENT. Expected error: Error 1452.

Q1.3 – Both mgr_ssn and Dno are NOT NULL

With both columns declared NOT NULL and the foreign keys enforced, inserting the first employee or department directly is impossible because the two tables depend on each other.

Solution:
Allow one of the columns to be NULL temporarily, insert the initial records in a suitable order, then update the foreign-key values after the referenced records exist. Alternatively, temporarily disable foreign-key checks and ensure all references are valid before re-enabling them.
